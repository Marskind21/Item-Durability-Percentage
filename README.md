# Item Durability Percentage

This is an utility resourcepack to show the percentage of durability left on items.

![](images/pickaxes.png)

This pack also includes a stack indicator for bundles (counting from 1 to 64) and different textures for crossbows depending on what arrow is currently loaded inside it.

![](images/bundles.png)

![](images/crossbows.png)
